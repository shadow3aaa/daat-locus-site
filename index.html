01How it works

You ask once.The work gets shared out.

  1. I

    Just ask

    Talk to Daat Locus the way you would to a capable assistant. Simple questions get a straight answer.

  2. II

    A team comes together

    For bigger tasks it brings in Actors and gives each a fitting name — Hermes plans the trip, Metis compares the options — choosing a suitable model for each by weighing ability against cost.

  3. III

    Everyone works at once

    Each Actor takes its own part and works at the same time as the others, on whichever of your devices suits the job.

  4. IV

    The answer comes back to you

    Updates and results arrive in the same conversation, in plain language. Curious? Open any Actor to see what it is up to.

03Safety

Capable,but always within bounds.

Actors work inside the sandbox your operating system provides. When a task needs to go further, it has to ask — and the final say stays with you.

  1. Sandbox

    Safe by default

    Commands and file changes run in your system's own sandbox on Windows, macOS and Linux. If the sandbox isn't available, the command simply doesn't run.

  2. Review

    A second look

    When an Actor needs more access, a separate check looks at exactly what is being asked for, then approves or declines it.

  3. Your call

    You have the last word

    If a request is declined, the Actor can bring it to Daat Locus, which checks what you have already allowed — and asks you whenever it isn't clear.

  4. No surprises

    Nothing happens twice

    Granting access never quietly re-runs anything. If work is interrupted, it is noted rather than repeated.

Administrator access is never automatic. On desktop, an Actor can ask to run one specific command with elevated rights. Each request is reviewed on its own and never becomes blanket permission.

04Devices

Laptop, desktop, phone —one assistant.

The same conversation everywhere

Sign in with the same account on each device and you'll find the same assistant and the same conversation. If one device goes offline, another takes over on its own.

A private connection

Your devices talk over end-to-end encrypted connections, through a relay you deploy yourself on Cloudflare Workers — no server to look after.

Happy on its own

Only have one computer? Everything works locally, with no extra setup.

05What Actors can do

They can use a computerwithout taking over yours.

A screen of their own

Actors operate desktop apps on a virtual screen, so your mouse and keyboard stay yours. Look in on them whenever you like.

A browser you share

Actors browse in a shared browser on your device, and you can use it too, like any other browser.

Careful web reading

Pages can be read as plain text without running their scripts, or opened in a separate, isolated view.

Files and commands

Actors edit files and run commands in the places you allow, without overwriting changes made in the meantime.

Your phone, too

On Android everything runs inside the app. Turn on phone control and Actors can operate your phone (Shizuku or root required).

Pick up where you left off

Import conversations from other AI apps and carry on with them here.

Build it yourself

You'll need Rust, Bun and wasm-pack.

git clone https://github.com/shadow3aaa/DaatLocus.git
cd DaatLocus
rustup target add wasm32-unknown-unknown
bun scripts/build-webui.ts
cargo run --locked -- serve
Connect several devices

Deploy the relay to your Cloudflare account once:

cd workers/signaling
bun install --frozen-lockfile
bunx wrangler login
bunx wrangler deploy

Then, on each device, turn on relay mode in account settings, enter the same address and sign in with the same account.

Notes for Linux

Sandboxed commands need bubblewrap and user namespaces enabled.
